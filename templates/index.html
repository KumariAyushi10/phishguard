HOW IT WORKS

AI Pipeline

01

Feature Extraction

{{ model_info.n_features if model_info else 46 }} numerical features are computed from the URL text: length, subdomains, IP hosts, suspicious TLDs, phishing keywords, brand impersonation, entropy and domain popularity.

02

Classification

Logistic Regression, Random Forest and Gradient Boosting were trained and compared; the best performer on validation data is used.

03

Explainability

Each feature is neutralised in turn to show which ones pushed the score towards phishing or towards legitimate.

04

Hybrid Verdict

The AI probability is blended with the VirusTotal engine results. If VirusTotal is unavailable, the AI model still produces a verdict.

05

Feedback Loop

Labels you submit are stored and included the next time the model is re-trained.
